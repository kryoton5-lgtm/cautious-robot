# Shubham Kadam · Computational Portfolio

**Curiosity. Computation. Clarity.**

An interactive portfolio bringing together scientific computing, applied machine learning, and AI evaluation. Built as a lightweight static website with no build step, external JavaScript dependencies, analytics, or tracking.

[LinkedIn](https://www.linkedin.com/in/shubhmkpmg/) · [GitHub](https://github.com/kryoton5-lgtm/)

## Website address

**https://kryoton5-lgtm.github.io/cautious-robot/**

The address above becomes available after GitHub Pages is enabled and deployment succeeds. Committing the source files alone does not activate hosting.

### Activate GitHub Pages

1. Open [Settings → Pages](https://github.com/kryoton5-lgtm/cautious-robot/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then **Save**.

No files need to be uploaded manually. The complete site is in the root of this repository. The empty `.nojekyll` file keeps the site as plain static assets.

## Experience

- **Mathematics in motion:** a draggable canvas sculpture with torus-knot, wave, and attractor modes.
- **Interactive computational lab:** synthetic observations, adjustable measurement noise, a bounded parameter fit, numerical error reporting, and CSV export.
- **Selected work:** filterable project cards and technical-overview dialogs describing the problem, approach, and validation.
- **Technical expertise:** detailed scientific-computing, data-analysis, machine-learning, GenAI, evaluation, and documentation sections.
- **Professional presentation:** dark/light themes, responsive layouts, keyboard navigation, a searchable command menu, reduced-motion controls, and a printable résumé.

## Run locally

From the repository directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.

## Files

```text
index.html          Portfolio content and accessible page structure
assets/site.css     Responsive styling, themes, and visual treatments
assets/site.js      Sculpture, numerical lab, dialogs, and navigation

```

## Demonstration and privacy boundaries

The browser lab is an educational, synthetic-data demonstration. Its fitted values are not claimed to be published research findings or results from a production reactor. Project artwork is illustrative. Private source code, client data, benchmark solutions, and exact grading thresholds are intentionally not included.

## Editing

Update `index.html` for portfolio copy, `assets/site.css` for appearance, `assets/site.js` for interactions and project summaries, and `resume.html` for the printable résumé. Keep relative asset paths so the site works both locally and under `/cautious-robot/` on GitHub Pages.
